# Friend trial feedback

Use this short sheet during the final household trial. Record the friend's words as accurately as possible instead of inventing positive feedback.

## Trial task

Ask the friend to:

1. Add or import one recipe.
2. Add it to a meal plan.
3. Generate meal suggestions or add a second meal manually.
4. Compare the enabled live stores.
5. Select the products they would actually buy.
6. Open one store link and explain what they would do next.

## Notes

- What felt useful immediately?
- What was unclear or slow?
- Did the ingredient quantities make sense?
- Did the package/excess calculation help decide between products?
- Were the store links trustworthy and easy to use?
- What would they change first?

## Submission-ready summary

- Friend's one-sentence reaction: [ADD QUOTE OR PARAPHRASE]
- Improvement implemented before submission: [ADD ONE QUICK FIX, OR “NONE”]
- Follow-up improvement left for later: [ADD ONE ITEM]

Not every suggestion needs to be implemented before submission. It is acceptable to document a useful follow-up, but implementing one small, clearly motivated improvement makes the trial evidence stronger.
